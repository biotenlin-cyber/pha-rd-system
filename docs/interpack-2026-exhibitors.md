## 1. 展会概览

| 项目 | 内容 |
|---|---|
| 展会名称 | **interpack 2026 — 国际加工与包装展览会** |
| 举办时间 | **2026 年 5 月 7 日（周四）— 5 月 13 日（周三）**，每天 10:00–18:00 |
| 举办地 | 德国杜塞尔多夫国际会展中心（**Messe Düsseldorf**） |
| 周期 | 三年一届，全球加工与包装行业**最高规格、最大规模**展会 |
| 规模 | 约 **2,500–2,800 家**参展商，预计 **17 万+** 专业观众，覆盖 **150+ 国家/地区** |
| 净展面积 | 约 **262,400 m²**，启用 **Halls 1–17 + 18a/b**（18 号馆为本届新增临时馆） |
| 8 大应用领域 | 食品、饮料、糖果、烘焙、医药、化妆品、非食品、工业品 |
| 子主题 | Components 区（位于 Hall 18），覆盖驱动/控制/视觉/输送等包装机械关键零部件 |
| 官方门户 | <https://www.interpack.com> · 互动展厅图：<https://www.interpack.com/en/Interactive_hall_plan> · 在线展商查询：<https://www.interpack.com/vis/v1/en/search> |

### 1.1 展厅按行业分布速记

| 展厅 | 主要行业 | PHA 关注度 |
|---|---|---|
| Hall 1 | 包装机械（部分整机商） | ★ |
| Hall 3 | **咖啡/可可/巧克力/坚果加工**（Probat、Bühler 等） | ★★★ |
| Hall 5–6 | 包装机械主力馆（Syntegon、KHS、Krones、Bosch Rexroth、Multivac 等部分） | ★★ |
| Hall 7 | **粘合剂、密封剂、功能涂层**（Paramelt 等） | ★★★ |
| Hall 8a | **造纸 / 卡纸 / 瓦楞 / 包装印刷**（最重要的纤维材料馆） | ★★★★★ |
| Hall 9 | **替代/创新材料**（生物基塑料、纤维替代方案） | ★★★★★ |
| Hall 10 | **塑料 / 生物塑料 / 软包材料**（BASF、TotalEnergies Corbion、Berry、ProAmpac） | ★★★★★ |
| Hall 11–14 | 食品/饮料/消费品/工业品包装机械 | ★★ |
| Hall 12 | 散装/袋装机械（HAVER & BOECKER 等） | ★ |
| Hall 15–17 | **医药 / 化妆品包装**（COESIA、IMA Group 集中） | ★★ |
| Hall 18a/b | Components 零部件区（驱动/视觉/传感/服务） | ★ |

> **PHA 团队建议路线**：Hall 8a（纤维基材）→ Hall 7（功能涂层）→ Hall 9（生物基替代材料）→ Hall 10（生物聚合物巨头）→ Hall 3（咖啡/可可下游应用）。
