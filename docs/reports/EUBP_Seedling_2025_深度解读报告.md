# 欧洲生物塑料协会 (EUBP) 《工业可堆肥材料制品认证方案》2025年10月版深度解读报告

> **报告类型**:法规与认证体系专项研究
> **报告对象**:PHA / PLA / PBAT / 纸基复合等可堆肥材料研发与产品团队
> **数据截止**:2026-05-05
> **来源等级**:EUBP 官方文件 + DIN CERTCO/TÜV 公告 + 行业权威解读交叉验证

---

## 0. 执行摘要 (Executive Summary)

2025 年 10 月,欧洲生物塑料协会(European Bioplastics e.V., **EUBP**)正式发布了 *Seedling Certification Scheme — Revision 2025* (官方文件名:`Seedling_FINAL_CertificationScheme_Revision_2025.pdf`),这是该体系自 2020、2023 版以来的第三次主要修订,也是与即将全面实施的欧盟 **PPWR (Regulation (EU) 2025/40)** 衔接的关键一步。

**修订主旋律可概括为四个字:"全、严、细、透"。**

| 维度 | 旧版 (2023) | 新版 (2025-10) | 净影响 |
|---|---|---|---|
| 单一有机成分独立测试门槛 | ≥1% | **>1% 且 <15% 区间需逐个独立测试** | 防止"打包送检"漏洞 |
| <1% 有机成分豁免**总额上限** | ≤ 5% | **≤ 3%** | 收紧 40% |
| 生态毒性测试 | 仅大组分 | **<0.1% 微量成分也纳入** | 范围扩大 |
| 标志文字 | "Seedling" | 增加 **"industrially compostable"** | 防消费者混淆"家庭堆肥" |
| 湿巾 / 无纺布 | 普通崩解测试 | 新增**专项**崩解协议 | 行业定向监管 |
| 化学回收单体 | 未明确 | 已认证 PLA 可使用**化学回收单体** | 行业利好 |

**对中国出口企业的核心信号**:出口至欧盟的可堆肥制品(PLA 餐具、PBAT 购物袋、纸塑复合餐盒、PHA 吸管等),**配方表必须重新审视**,尤其是 1%–15% 区间的助剂、色母粒、改性剂将面临**逐项送检**压力;助剂总和的"小窗口"从 5% 收紧到 3%。

> ⚠️ 文章原文称"2026 年 1 月生效"——经核实,EUBP/DIN CERTCO 官方表述为:**对所有新申请立即生效;对现有证书在续证(3 年有效期到期)时强制采用新版**。"2026 年 1 月"更可能是中文媒体根据 PPWR 时间表的概括,**并非官方"一刀切"日期**。

## 1. 报告背景与文章真实性核实

### 1.1 文章来源与原文核心论点

被解读的中文文章(微信公众号"秸品优衣"等渠道传播)的核心断言:

1. 2025 年 10 月 EUBP 发布新版《工业可堆肥材料制品认证方案》;
2. 2026 年 1 月生效;
3. 认证标志为 Seedling(小树苗);
4. **新增要求**:含量 >1% 至 <15% 的每种有机成分,需证明其最终生物降解性;碳酸钙不属于有机物,无需证明;
5. **调整门槛**:含量 ≤1% 的有机化合物(无需测定生物降解性)的总占比上限从 5% 降至 3%。

### 1.2 真实性评估矩阵

| 论点 | 核实结论 | 证据 |
|---|---|---|
| 新版认证方案存在 | ✅ **属实** | EUBP 官网正式页面 `seedling-certification-scheme-october2025/` 与 PDF 文件存档 |
| 发布主体为 EUBP | ✅ **属实** | 由 EUBP 与 DIN CERTCO/TÜV AUSTRIA 联合维护 |
| Seedling 标志 | ✅ **属实** | 注册商标,沿用至今 |
| 1%–15% 独立生物降解测试 | ✅ **属实** | EUBP 文件 Annex B.2 与多家认证机构通告 |
| 碳酸钙等无机物豁免 | ✅ **属实**(行业惯例) | EN 13432 一贯做法,新规未变 |
| **5%→3% 总额上限收紧** | ⚠️ **方向属实,具体数字以官方 PDF 为准** | 多渠道间接确认,作者尚未直读 PDF 二级条款 |
| **2026 年 1 月生效** | ⚠️ **简化表述** | 官方为"新申请立即生效、续证时切换",非全行业一刀切日期 |

## 2. EUBP / Seedling 认证体系基础架构

### 2.1 认证主体生态图

```
        ┌────────────────────────────────────┐
        │   European Bioplastics e.V. (EUBP) │  ← 标准制定与商标持有
        └─────────────────┬──────────────────┘
                          │ 授权
            ┌─────────────┴──────────────┐
            ▼                            ▼
   ┌────────────────┐          ┌────────────────────┐
   │ DIN CERTCO (DE)│          │ TÜV AUSTRIA Belgium│   ← 认证执行机构
   └────────┬───────┘          └─────────┬──────────┘
            │                            │
            ▼                            ▼
   ┌────────────────────────────────────────────────┐
   │  申请企业:材料商 / 中间品商 / 终端产品商         │
   └────────────────────────────────────────────────┘
```

### 2.2 标准基底

Seedling 体系**不是一个独立标准**,而是建立在以下国际/欧洲标准之上的"复合认证":

| 标准 | 性质 | 角色 |
|---|---|---|
| **EN 13432:2000** | 欧洲包装可堆肥标准 | 主标尺 |
| **EN 14995:2006** | 非包装塑料可堆肥 | 非包装制品 |
| **ISO 17088:2021** | 国际可堆肥塑料 | 国际等效 |
| **ISO 18606:2013** | 国际可堆肥包装 | 国际等效 |
| **ASTM D6400** | 美国可堆肥 | 跨大西洋互认参考 |

### 2.3 Seedling 通过的"四关"

任何材料/产品要拿到 Seedling 标志,必须**同时**通过以下四项考核(EN 13432 框架):

```
 ① 化学特性 (Chemical Characterisation)
       │  ├─ 重金属 12 项限值
       │  ├─ 氟含量 ≤100 mg/kg(防 PFAS)
       │  └─ 挥发性固体 ≥50%
 ② 生物降解性 (Biodegradability)
       │  └─ 6 个月内 ≥90% 矿化为 CO₂
 ③ 崩解性 (Disintegration)
       │  └─ 12 周内 ≥90% 通过 2mm 筛
 ④ 生态毒性 (Ecotoxicity)
       │  └─ OECD 208 植物生长试验
       │     发芽率 / 生物量 ≥ 空白对照 90%
```

Seedling 在以上之上,再叠加 EUBP 商标使用规则与年度合规审计。

## 3. 2025 年 10 月版六大核心变更详解

### 3.1 变更一:**1%–15% 有机成分独立测试**(影响最大)

**条款解读**:
- 旧规:产品中**含量 ≥1%** 的每种有机成分,理论上需通过最终生物降解测试,但实操中允许"以混合物送检"。
- 新规:**>1% 且 <15%** 区间内的**每一种**有机组分,**必须独立**(以纯物质或代表性混合物形式)通过 ISO 14855 等测试,出具独立证书。

**意图**:堵住"以混合物的整体降解率掩盖单一组分不合格"的漏洞。例如某厂家配方为:
- A 树脂 60%(已认证)
- B 改性剂 4%(未单独认证)
- C 增塑剂 3%(未单独认证)
- D 偶联剂 2%(未单独认证)
- 其他 31%

旧规下,B+C+D 可能以"复合改性料"打包送检,只要混合物达 90% 矿化即可。新规要求 B、C、D **各自**出具独立测试报告。

### 3.2 变更二:**<1% 有机成分豁免总额从 5% 收紧至 3%**

**条款解读**:
- 单一有机成分 <1%:仍可豁免单项测试(de minimis 原则)。
- 但所有此类豁免成分的**质量分数总和**:
  - 旧规 ≤ **5%**
  - 新规 ≤ **3%**

**直观理解**:
- 这是给"印刷油墨、抗氧剂、滑爽剂、催化剂残留、脱模剂、香料、紫外吸收剂……"等**微量功能助剂**留的"信封空间"。
- "信封"由 5% 缩到 3%,意味着配方中**不被深度审查的灰色地带减少了 40%**。
- 实际操作中,有机色母粒、含磷阻燃剂、聚合物加工助剂(PPA)等如果总量超过 3%,必须将其中某一种"挪出"豁免区——要么提供独立生物降解证明,要么去除/替换。

### 3.3 变更三:**0.1% 以下成分纳入生态毒性测试**

**条款解读**:
- 旧规:生态毒性测试主要针对配方中的主要成分。
- 新规:**含量 <0.1%** 的成分(往往是微量但生物活性强的物质,如重金属催化剂残留、特定有机助剂)**也需证明**对堆肥蚯蚓 / 植物 / 微生物群落无负面影响。

**意图**:对应欧盟 REACH 与 PPWR 对"故意添加微塑料"和"持久性有毒物质"的零容忍趋势。

### 3.4 变更四:**Seedling Logo 文字调整**

**条款解读**:
- 标志中明确加入 **"industrially compostable"** 字样。
- 防止消费者将 Seedling 误认为"家庭堆肥可降解"(后者是单独的 OK Compost HOME 标识)。

**意图**:配合 PPWR 第 9 条对**误导性环保声明**的规制。

### 3.5 变更五:**湿巾 / 无纺布专项崩解测试**

**条款解读**:
- 针对一次性湿巾、无纺擦拭布、无纺包装内衬等"非典型形态"产品,新增**专门**的崩解测试协议(更严苛的水流冲击与机械应力模拟)。
- 背景:2024 年起欧盟多国(法、德、英)对一次性湿巾立法收紧。

### 3.6 变更六:**允许使用化学回收单体生产已认证 PLA**

**条款解读**:
- 已通过 Seedling 认证的 PLA 可在不重新认证的前提下,使用**化学回收(解聚-再聚合)路径**得到的乳酸单体再生产。
- 这是对 EUBP 成员中 NatureWorks、TotalEnergies-Corbion 等推动的"PLA 化学循环 2.0"计划的政策响应。

## 4. "1% / 3% / 15%" 阈值体系深度解读 — 必读章节

### 4.1 三层阈值的逻辑全貌

```
         ┌──────────────────────────────────────────┐
         │   产品有机成分(扣除无机填料、水分后)      │
         └─────────────────┬────────────────────────┘
                           │ 按单一成分质量分数划分
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
    < 1% 单项           1% – 15%            ≥ 15%
        │                   │                  │
   ┌────┴────┐         ┌────┴────┐        ┌────┴────┐
   │ 单项豁免 │         │ 必须独立 │        │ 必须独立 │
   │ 不需测试 │         │ 送测最终 │        │ 送测最终 │
   └────┬────┘         │ 生物降解 │        │ 生物降解 │
        │              └─────────┘        └─────────┘
   ┌────┴────────────┐
   │ 总和 ≤ 3% (新规) │
   │ (旧规 ≤ 5%)      │
   └─────────────────┘
```

### 4.2 阈值的三个性质澄清

| 性质 | 内容 |
|---|---|
| **针对对象** | **化学成分的质量分数**(% w/w),不是"涂层厚度"、"层数"、"面积比"或"功能层" |
| **不计入分母** | 无机物(碳酸钙、滑石粉、二氧化钛、玻璃纤维)、水分、天然纤维素未化学修饰部分 |
| **强制性等级** | 这是**通过认证的"门槛性"硬指标**,不是"建议",违反任一项即不予颁证 |

### 4.3 易错认知澄清

| 错误理解 | 正确解读 |
|---|---|
| "PE 涂层 <3% 就可以拿 Seedling" | ❌ 错。PE 是石化非降解物,即使 0.5% 也违反 EN 13432 对"非生物降解残留"的限制。3% 信封只是给**可豁免单测**的助剂,不是给非降解物开后门 |
| "几个成分各 0.9%,就可以无限叠加" | ❌ 错。单项可豁免测试,但**总和必须 ≤3%**。4 种 ×0.9% = 3.6% 已超标 |
| "≥15% 就不用测了" | ❌ 完全相反。≥15% 是绝对主成分,**永远必须**通过独立测试(本来就如此,新规未变) |
| "1%–15% 区间是新发明" | ⚠️ 部分对。≥1% 必测原则一直存在,**"1%–15% 必须逐项独立"** 是新增的"防混合送检"要求 |
| "碳酸钙不限量" | ⚠️ 部分对。CaCO₃ 不参与有机成分阈值计算,但仍受"挥发性固体 ≥50%"总要求约束(无机物太多会拉低 VS 比例) |

## 5. 对企业研发与生产的实际影响——分行业拆解

### 5.1 对 PHA 行业的影响(本系统主体业务)

PHA(聚羟基脂肪酸酯)作为**完全生物基**且**多环境可降解**的材料,新规影响相对友好:

| 维度 | PHA 立场 | 新规影响 |
|---|---|---|
| 主成分降解性 | PHA 本身在工业堆肥、海水、土壤均可降解 | ✅ 利好,产品差异化更突出 |
| 改性体系 | 多采用 PLA/PBAT/纤维素纤维共混 | ⚠️ 共混伙伴需逐一独立认证 |
| 助剂体系 | 加工窗口窄,常需较多润滑剂、成核剂 | ⚠️ 注意助剂总和 ≤3% 信封 |
| 单体来源 | 微生物发酵,化学回收路径正在探索 | ✅ "化学回收单体"条款为未来 PHA 解聚-再聚提供政策空间 |

**研发建议**:
1. 优先选择**已经获得 Seedling 单项认证的共混伙伴材料**(如 Ecoflex、Luminy PLA),减少自行送检负担。
2. 助剂供应商应**提前锁定**已具备生物降解和生态毒性数据的产品(如 BASF、Clariant 的"compostable-grade"系列)。
3. 建立**配方表 vs. 3% 信封**自动化校验机制(可在 BOM/PLM 系统中加入合规字段)。

### 5.2 对 PLA / PBAT 共混料商的影响

- 共混型号(如 PLA + PBAT + 改性剂)若属于 1%–15% 区间的改性组分,**必须**取得纯组分独立测试报告。
- 大量"自主配方"小厂将面临**测试成本翻倍**(每项 ISO 14855 ≈ €15,000–25,000 / 6 个月周期)。

### 5.3 对纸塑复合制品(纸杯/纸碗/餐盒)的影响

**纸杯/纸碗 Seedling 认证的关键不在 3%,而在涂层化学性质本身。**

| 涂层类型 | 占比典型值 | 是否能拿 Seedling | 受 3% 阈值影响 |
|---|---|---|---|
| **PE 聚乙烯涂层** | 5%–15% | ❌ **完全不可能** | 与 3% 无关,因 PE 不可降解 |
| **EAA / EMAA 增粘层** | 0.5%–2% | ❌ 同上 | 即便 <1%,也属"非降解残留"被禁 |
| **PLA 涂层** | 5%–18% | ✅ 可,需 PLA 已 Seedling 认证 | ≥15% 时绝对必测,本来就要 |
| **PBS / PBAT 涂层** | 5%–15% | ✅ 可 | 同上 |
| **PHA 水性涂层(新兴)** | 1%–10% | ✅ 可 | 1%–15% 区间需独立测试报告 |
| **水基生物聚合物涂层** | 1%–8% | ✅ 可 | 同上 |

> 🎯 **关键判断**:对纸杯而言,**先决条件是涂层本身可降解**;新规的 3% 信封只对**油墨、防水助剂、施胶剂、湿强剂、热熔粘合点**等微量成分有约束。

### 5.4 对色母粒 / 助剂供应商的冲击

- 有机色母粒的**载体树脂**通常占成品的 1%–3%,正好踩在新规"双重门槛"上(单项 ≥1% 必须独立测试 + 总和 ≤3% 限制)。
- 含氟、含溴、含镉的功能助剂将被直接淘汰(EN 13432 重金属与氟限值)。

### 5.5 对中国出口企业的合规雷区

| 雷区 | 表现 | 对策 |
|---|---|---|
| 沿用国内 GB/T 19277 数据 | 中国 GB/T 19277 与 EN 13432 测试条件略有差异,数据**不能直接跨用** | 重新在 EUBP 认可实验室送检 |
| 对"工业堆肥 = 全场景可降解"误用 | 在欧盟宣传时混淆"industrial / home / soil / marine" | 严格按 Seedling 文字使用 |
| 忽视微量助剂供应商资质 | 助剂厂商未提供可降解证明 | 建立"合规助剂白名单" |
| 涂层结构未声明 | 多层复合膜未拆分各层占比 | 提供完整 BOM + 各层质量分数 |

## 6. 与欧盟法规体系的衔接

### 6.1 PPWR (Regulation (EU) 2025/40) 时间表

```
2025-02-11    PPWR 生效
2025-10-XX    EUBP Seedling Revision 2025 发布
2026-08-12    PPWR 主体条款适用
2028-02-12    PPWR 第 9 条「可堆肥包装」强制要求生效
                  └── 强制可堆肥品类: 茶包、咖啡袋、果蔬不干胶标签、
                       果蔬塑料袋(成员国可选)
```

### 6.2 EN 13432 标准本身的修订路径

- 欧盟委员会已正式委托 CEN 启动 **EN 13432 修订**。
- 目前的 Seedling 2025 版可视为对 EN 13432 修订的"先行测试"——许多收紧的要求(如 0.1% 生态毒性、PFAS 防控)预计将被纳入新版 EN 13432。
- 新版 EN 13432 预计 **2027–2028** 发布。

### 6.3 与"绿色声明指令"(Green Claims Directive)的联动

新版 Seedling 加入 "industrially compostable" 字样,正是为了符合 Green Claims Directive 对"任何环保声明必须可验证、不可误导"的要求。**仅打 Seedling 标志而无文字说明,在欧盟将被视为不充分信息披露**。

## 7. 企业应对路线图

### 7.1 短期 (0–6 个月)

- [ ] **配方表全面盘点**:逐项标注各有机成分质量分数,识别 1%–15% 区间组分清单。
- [ ] **3% 信封校核**:计算所有 <1% 有机成分质量分数总和,若 >3%,启动配方调整。
- [ ] **联系认证机构**(DIN CERTCO / TÜV AUSTRIA),确认现有证书过渡安排,获取新版 Annex B 测试方法清单。
- [ ] **供应商证书梳理**:要求所有助剂、色母粒、改性剂供应商提供其原料的 Seedling/EN 13432 子认证。

### 7.2 中期 (6–18 个月)

- [ ] **关键组分独立送检**:对 1%–15% 区间未持有独立认证的组分,启动 ISO 14855 (180 天)测试。
- [ ] **生态毒性扩展测试**:对 <0.1% 微量成分,补充 OECD 208 植物试验与蚯蚓急性毒性试验。
- [ ] **包装/产品标识更新**:Seedling logo 同步增加 "industrially compostable" 文字,准备多语言版本。
- [ ] **建立合规 BOM 系统**:在 PLM / ERP 中增加合规字段(占比、生物降解证书号、生态毒性 OK 标记)。

### 7.3 长期 (18 个月以上)

- [ ] **跟踪 EN 13432 新版征求意见稿**(预计 2026–2027 公开),提前介入。
- [ ] **PHA / 化学回收路径布局**:利用新规对化学回收单体的开放,提前规划闭环回收专利与产能。
- [ ] **拓展跨标识互认**:同步对标 OK Compost HOME / TÜV OK Marine / OK Soil,扩大产品认证矩阵。

## 8. 风险提示与不确定因素

1. **5%→3% 具体数字** 来自二次行业解读,作者团队尚未直读 EUBP PDF 中相应条款的具体段落与图表;建议在重大决策前由企业法务/合规部门**直接索取 EUBP 原始文件**确认。
2. **生效日期** 各认证机构可能分别公告不同的过渡安排,跨认证机构的客户需分别确认。
3. **PFAS 新限值** 目前 EN 13432 对总氟含量为 100 mg/kg,但欧盟 REACH 对 PFAS 的更严限值正在制定,Seedling 后续可能进一步收紧。
4. **海外互认** 美国 BPI、澳大利亚 ABA 等体系是否同步收紧尚不确定,企业出口多国时应分别评估。
