# pha-rd-system
PHA材料研发及产品开发与专利管理系统

## 都佰城介绍

都佰城集团（DBC Group）是一家专注于生物基可降解材料研发、生产与应用的高新技术企业，致力于以创新材料推动绿色低碳产业升级，为全球客户提供环境友好的可持续解决方案。

### 主营业务

- **PHA 材料研发**：聚焦聚羟基脂肪酸酯（PHA）等生物基可降解材料的合成工艺、改性配方及量产工艺研究。
- **产品开发**：基于 PHA 材料开发包装、餐饮具、日化、农业地膜、医疗器械等下游应用产品。
- **专利与知识产权管理**：构建覆盖材料、工艺、装备、应用的全链条知识产权体系。
- **产业化与市场推广**：推动 PHA 材料在国内外市场的规模化应用与商业化落地。

### 核心优势

- **技术领先**：拥有自主可控的菌种、发酵工艺与下游提取技术，产品性能稳定。
- **全产业链布局**：覆盖原料、单体、聚合、改性、制品到回收的完整闭环。
- **绿色可持续**：所生产 PHA 材料可在自然环境（包括土壤、淡水及海洋）中实现完全生物降解。
- **专利护城河**：在材料配方、生产工艺、应用产品等多个领域积累了丰富的专利成果。

### 愿景与使命

以生物制造引领绿色变革，让可降解材料走进千家万户，助力实现"双碳"目标和联合国可持续发展目标（SDGs）。
