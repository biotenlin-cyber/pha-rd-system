> 项目:含纤维素纳米晶(CNC)与单宁酸生物基交联剂的 PHA 水性纸基阻隔涂料及其制备方法

## 1. 立项目标

依据国家发改委《"十四五"塑料污染治理行动方案》、欧盟 PPWR、美国 FDA / 加州 AB 1200 对 PFAS 食品接触材料的限令,以及国内 GB 4806 系列食品接触材料新标的实施进度,**全生物基、非氟、非锆、可工业堆肥与海洋降解的水性 PHA 阻隔涂料**已成为食品包装产业的强需求。本项目拟以本企业 PHA(P3HB4HB / PHBHHx / PHBV)发酵产能为基础,开发一项配方型 + 工艺型双布局的发明专利,在(1)绕开现有强专利权项、(2)突出全生物基食品安全卖点、(3)兼顾纸基同源可回收性 三个维度建立技术壁垒。

### 2.3 学术文献(背景技术 + 创造性突破依据)

- Stable aqueous dispersions of PHBV polymer for barrier paper coating(*Industrial Crops and Products*, 2024):用 SDS + 瓜尔豆胶稳定 PHBV 水分散体 — **非交联**,本案在交联剂选择上具有创造性提升;
- Improvement of paper resistance against moisture and oil by coating with PHBV/PCL(*Applied Sciences*, 2021):PHBV/PCL 共混,**非全生物基**,本案以单宁酸 + CNC 替代 PCL 部分功能;
- Tannic acid as a green crosslinker for biopolymer films(*Carbohydrate Polymers*, 2022 系列):证明单宁酸对纤维素 / 蛋白具备交联效应,但**未与 PHA 水性体系结合**;
- CNC enhances oxygen barrier of biopolymer films(*ACS Sustainable Chem. Eng.*, 多篇):CNC 在 PLA 中提升阻氧 30–60%,但**未在 PHA 水性涂料中报道**;
- 交叉空白:**"PHA + CNC + 单宁酸"** 三元生物基阻隔配方在公开文献和现有专利中均未见报道。

            │       +  纤维素纳米晶 CNC(0.5–8 wt%)        │

## 4. 技术方案构思

### 4.1 创新点(可被独立权利要求覆盖)

1. **成分创新**:首次将"单宁酸的多酚酯化交联"与"CNC 的层状阻气强化"协同应用于 PHA 水性纸基阻隔涂料,无需锆 / 蜡 / PVOH / PBAT 等共聚组分。
2. **粒径创新**:PHA 水分散体颗粒 D50 限定 **150–450 nm**,既突破 D7 (0.1–1 µm) 与 D4 (0.5–5 µm) 的过宽布点(可主张本区间是阻氧性能拐点),又避开两者的中位数。
3. **交联机理创新**:单宁酸 — PHA 末端羧基的 H 键 / 酯化 + 单宁酸 — CNC 羟基的 π-OH 协同,室温 120 ℃ 干燥即可成型,无需高温烘烤 / UV 引发。
4. **工艺创新**:湿法球磨 + 高压均质两段法,无需熔融预混(避开 D5 / D6 的 150–170 ℃ 熔融工艺权项),能耗显著下降。
5. **应用创新**:同时实现 Cobb₆₀ ≤ 12 g/m²、Kit ≥ 11 级、OTR ≤ 25 cc·µm/m²·d·atm、纤维回收率 ≥ 96%、家庭堆肥(EN 13432)与海洋降解(ASTM D7081)双认证可达。

### 4.2 创造性论证(三步法)

| 步骤 | 内容 |
|---|---|
| 最接近现有技术 | **D1(WO2020036843)** — PHA 水性分散体 + 锆系交联剂 + 纸基阻隔涂层 |
| 区别特征 | (a) 用单宁酸替代锆系交联剂;(b) 引入 CNC 作为板层阻气填料;(c) PHA 颗粒 D50 限定 150–450 nm |
| 实际解决的技术问题 | 在去除锆系金属交联剂(食品安全 / 环保争议)的同时维持甚至提升阻油 / 阻气性能,并提升纸纤维回收率与海洋降解性 |
| 技术效果(实施例支持) | Kit 由 D1 的 8–10 提升至 ≥ 11;OTR 下降 30%(对比无 CNC 例);海洋降解 90 d 失重 ≥ 60%(D1 体系含锆,海洋降解失重 ≤ 35%);食品接触迁移测试满足 GB 4806.8 |
| 创造性结论 | 现有技术未提出"用单宁酸替代锆 + 加入 CNC"组合的技术启示;且组合后表现出**协同效应**(synergy) — 单宁酸单独使用时阻气提升有限,CNC 单独使用时阻油不达标,两者共存方能突破。具有**显著的创造性**。 |

### 4.3 实用性

- 全部原料商业可得:PHA(自产或外购)、CNC(国内已有 50 t/a 产能,如桂林某厂、华南理工孵化企业)、单宁酸(食品级,大宗)、SDS / Tween 系表面活性剂、瓜尔豆胶。
- 工艺设备为通用:卧式砂磨机、高压均质机、双辊涂布 / 棒涂 / 淋涂头。
- 可在现有造纸涂布生产线小改即上车。

## 5. 权利要求布局策略

```
1. 独立产品权:水性纸基阻隔涂料(组分 + 配比 + PHA 粒径)
   ├ 2. 从属:PHA 选自 P3HB4HB / PHBHHx / PHBV / PHB,优选 P3HB4HB
   ├ 3. 从属:CNC 长径比 ≥ 50,直径 5–20 nm
   ├ 4. 从属:单宁酸为水解单宁(galloyl tannin),含量 0.1–3 wt%
   ├ 5. 从属:PHA D50 150–450 nm,优选 200–350 nm
   ├ 6. 从属:表面活性剂为 SDS / SDBS / Tween 80 / Span 60 中的一种或多种
   ├ 7. 从属:流变改性剂为瓜尔豆胶 / 黄原胶 / 羟乙基纤维素中的一种或多种
   └ 8. 从属:固含量 25–55 wt%,黏度 100–800 mPa·s

9. 独立方法权:制备方法(湿法砂磨 + 高压均质 + 单宁酸/CNC 后混)
   ├ 10. 从属:湿法砂磨参数(锆珠粒径、转速、时间)
   ├ 11. 从属:高压均质参数(50–120 MPa,2–4 道)
   └ 12. 从属:单宁酸先与 CNC 预混分散后再与 PHA 分散体混合

13. 独立应用权:涂层纸 / 纸板及其制备(基纸定量 + 涂布量 + 干燥温度)
   ├ 14. 从属:涂布量 4–15 g/m²(干基)
   ├ 15. 从属:干燥温度 100–140 ℃,梯度干燥
   ├ 16. 从属:Cobb₆₀ ≤ 12 g/m²,Kit ≥ 11,OTR ≤ 25 cc·µm/m²·d·atm
   └ 17. 从属:符合 GB 4806.8 食品接触安全与 EN 13432 / ASTM D6400 工业堆肥
```

## 6. 风险点与缓解

| 风险 | 评估 | 缓解措施 |
|---|---|---|
| Danimer **D1** 主张"含交联剂"可能被审查员引为最接近 X 文献 | 中 | 在权项 1 明确列出"单宁酸",而非泛指"交联剂";突出非锆、生物基 |
| **D7(CN119777197A)** 已主张 PHA D50 ≤ 1 µm | 中-高 | 限定 150–450 nm,且独立权项中以"CNC + 单宁酸 + 粒径区间"作为不可分割技术特征,粒径只是从属特征 |
| **D2(Kemira)** 主张 PHA + 其它生物聚合物的宽组合 | 中 | 单宁酸非聚合物(为多酚天然产物),CNC 为纳米填料 — 在分类学上可与"其它生物聚合物"区分;说明书需明确技术术语区分 |
| 单宁酸与 PHA 酯化的反应程度难以量化 | 低 | 用 FTIR(C=O 谱带位移)、DSC、凝胶分数论证交联确实发生 |
| 学术文献已分别报道 CNC + PHA、单宁酸 + 蛋白 | 低 | 三元组合无报道,且**协同效应**为创造性核心,审查员通常认可协同效应作为创造性证据 |
