## 3. 关键技术主题（按权利要求方向归纳）

1. **水性 PHA 分散体（PHA Dispersion）配方**
   - 颗粒度：D50 0.1–5 µm（决定涂膜致密度与防油/防水）
   - 固含量：水 35–75%，PHA 25–65%
   - 助剂：稳定剂、表面活性剂、流变改性剂、消泡剂、流平剂、交联剂（金盏花油、氨锆碳酸盐、阴离子羟基化锆聚合物等）
   - 代表：WO2020036843、US12258469、US20240279407、CN117769583A、CN119777197A

2. **PHA + 其它可降解聚合物共混乳液**
   - PHA + PBAT + PVOH 三元（CN120026524B）
   - PHA + 生物蜡（WO2024206601）
   - PHA + PCL / PLA 等（学术 / 涂布纸方向）
   - PHA + 三元共混 + 原位扩链（CN119912795B）

3. **直接利用 PHA 滤饼（Cake）路线**
   - 跳过干燥步骤，能耗低、成本低（US20230220155）

4. **应用与工艺**
   - 食品接触类纸杯 / 餐盒 / 烘焙纸 / 冷饮杯 / 汉堡纸 / 模塑纤维 / 纸吸管
   - 涂布工艺：刮刀、棒涂、淋涂、转移涂布（US20250162303）；
   - 干燥：80–150 ℃（含梯度干燥，CN120759147B）
   - 性能：Cobb₆₀ 10–15 g/m²、Kit ≥ 10、OTR/WVTR 显著降低、纤维回收率 95–98%

5. **添加剂 / 改性方向**
   - PHA 作涂料流变 / 增稠添加剂（BYK：WO2012098041）
   - 反应性单体（EP1330503）
   - 交联与原位扩链（CN119912795B）

## 4. FTO 与研发建议

1. **重点回避 / 关注的核心专利**
   - Danimer：WO2020036843 / US11866606（覆盖 35–75% 水 + 25–65% PHA + 交联剂的水性体系，权项较宽）
   - Kemira：US12258469（水 + PHA + 其它生物聚合物 + 稳定剂 + 流变剂 + 交联剂的多组分水性体系）
   - CJ：US20240279407（粒径 0.5–5 µm 的 PHA 分散体制备）
   - BYK：WO2012098041（PHA 作添加剂）

2. **可探索的差异化方向**
   - 非交联 / 替代型交联体系（避开锆系交联剂）
   - 极小颗粒（D50 < 0.1 µm 的纳米分散体）
   - 非熔融预共混制备工艺（避开 CN120026524B 的 150–170 ℃ 熔融预混 + PVOH 路线）
   - 海洋可降解 / 食品安全等级证书绑定的配方
   - 与本企业菌种 / 共聚组成（如 P34HB、PHBHHx 高 HHx 比例）匹配的乳化体系

3. **下一步检索建议**
   - 拉取以上关键文献的同族（CN / JP / KR / IN / BR）并核查 INPADOC 同族
   - 在 CNIPA / 智慧芽 / Patsnap 中按 IPC 分类号 D21H 19/20、D21H 19/28、C09D 167/04 复检
   - 增加 PHB / PHBV / PHBHHx / P34HB 单一成分关键词的中英文交叉检索
   - 对中国厂商（Bluepha、PhaBuilder、Bioten 都佰城、合众化工等）按申请人名扫扫专利列表
